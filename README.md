## English

### Features
- **Ranked by outlier score:** a reel's views divided by the account's median views.
- **Stats inside Instagram:** views, likes, comments and publish date under every reel.
- **Content research:** reels from several accounts in one grid, best performers first, with a date filter.
- **Library and folders:** save reels, download a whole folder in original quality, export CSV / JSON.
- **Full video control:** ±5 s (10 with Shift), frame by frame (10 with Shift), speed, volume and a seek bar.
- **Dark and light** in Instagram's own colours, inside Instagram or in a separate window.
- **Arabic and English:** switch the extension's language at any time.

### Install
1. Download [`Reels-Analysis.zip`](https://github.com/aminellkadaoui/amine-reels/releases/latest/download/Reels-Analysis.zip) and unzip it.
2. Open `chrome://extensions` (or `brave://extensions`).
3. Turn on **Developer mode**, click **Load unpacked** and pick the unzipped folder.
4. Open Instagram while logged in, go to any profile and open the **Sorted reels** tab.

To update: download the new zip over the old folder, then click **Update** on the extension card.

### Shortcuts (under the reel)
`Space` / `K` play · `J` `L` / `←` `→` 5 s · `,` `.` one frame · `[` `]` `\` speed · `M` `↑` `↓` volume · `0`–`9` jump · `Alt+Shift+R` reels grid

### Privacy
Runs only in your browser. No server, no data collection, nothing sent anywhere. What you save stays on your device. See [privacy &amp; terms](https://aminellkadaoui.github.io/amine-reels/privacy.html?lang=en).

### Code
- `extension/` — the extension (Manifest V3, plain JavaScript, no build step).
- `docs/` — the landing page (GitHub Pages), Arabic and English.

## العربية

### الميزات
- **ترتيب بنقاط التميّز:** مشاهدات الريل ÷ وسيط مشاهدات الحساب.
- **إحصاءات كل ريل داخل إنستغرام:** المشاهدات، الإعجابات، التعليقات، تاريخ النشر.
- **تحليل المحتوى:** عدة حسابات في شبكة واحدة مرتبة بالأعلى أداءً، مع فلتر بالتاريخ.
- **مكتبة ومجلدات:** حفظ، وتنزيل المجلد كله بالملف الأصلي، وتصدير CSV / JSON.
- **تحكّم كامل في الفيديو:** ±5 ث (10 مع Shift)، فريم بفريم (10 مع Shift)، السرعة، الصوت، شريط التنقل.
- **داكن وفاتح** بألوان إنستغرام، داخل واجهة إنستغرام أو في نافذة منفصلة.
- **عربي وإنجليزي:** غيّر لغة الإضافة متى شئت.

### التثبيت
1. نزّل [`Reels-Analysis.zip`](https://github.com/aminellkadaoui/amine-reels/releases/latest/download/Reels-Analysis.zip) وفك ضغطه.
2. افتح `chrome://extensions` أو `brave://extensions`.
3. فعّل **Developer mode**، ثم **Load unpacked** واختر المجلد.
4. افتح إنستغرام وأنت مسجّل الدخول، ثم تبويب **«ريلز مرتبة»** في أي حساب.
