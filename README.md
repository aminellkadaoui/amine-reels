<h1 align="center">Amine Reels</h1>
<p align="center">إضافة مجانية ومفتوحة المصدر لـ Chrome وBrave لاكتشاف أنجح الريلز في أي حساب على إنستغرام.<br>
Free, open-source Chrome &amp; Brave extension to find the best-performing Instagram reels.</p>

## الميزات
- **ترتيب بنقاط التميّز:** مشاهدات الريل ÷ وسيط مشاهدات الحساب.
- **إحصاءات كل ريل داخل إنستغرام:** المشاهدات، الإعجابات، التعليقات، تاريخ النشر.
- **تحليل المحتوى:** عدة حسابات في شبكة واحدة مرتبة بالأعلى أداءً، مع فلتر بالتاريخ.
- **مكتبة ومجلدات:** حفظ، وتنزيل المجلد كله بالملف الأصلي، وتصدير CSV / JSON.
- **تحكّم كامل في الفيديو:** ±5 ث (10 مع Shift)، فريم بفريم (10 مع Shift)، السرعة، الصوت، شريط التنقل.
- **داكن وفاتح** بألوان إنستغرام، داخل واجهة إنستغرام أو في نافذة منفصلة.

## التثبيت
1. نزّل [`Amine-Reels.zip`](https://github.com/aminellkadaoui/amine-reels/releases/latest/download/Amine-Reels.zip) وفك ضغطه.
2. افتح `chrome://extensions` أو `brave://extensions`.
3. فعّل **Developer mode**، ثم **Load unpacked** واختر المجلد.
4. افتح إنستغرام وأنت مسجّل الدخول، ثم تبويب **«ريلز مرتبة»** في أي حساب.

## Install (English)
1. Download [`Amine-Reels.zip`](https://github.com/aminellkadaoui/amine-reels/releases/latest/download/Amine-Reels.zip) and unzip it.
2. Open `chrome://extensions` (or `brave://extensions`), turn on **Developer mode**, click **Load unpacked** and pick the folder.
3. Open Instagram (logged in), go to any profile and open the **«ريلز مرتبة»** tab.
